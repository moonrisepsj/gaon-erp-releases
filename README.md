# GAON ERP · Windows 다운로드

가온 ERP의 Windows용 클라이언트와 간단한 사용 매뉴얼을 배포하는 공개 저장소입니다.
업무 데이터, 서버 소스, 직원 정보, API 키, 기존 개발 저장소의 기록은 포함하지 않습니다.

## 다운로드

`0.2.0-preview.3` 검수본을 공개했습니다. Windows CI의 설치·설치된 앱 실행·제거 검사와 배포 파일 해시 대조를 통과했습니다.

`0.2.0-preview.4`는 새 기기 알림 self-test가 포함된 Windows 후보입니다. 아직 설치본 공개와 실제 직원 기기 표시·클릭 검수를 완료하지 않았으므로 아래 다운로드는 검증이 끝난 `preview.3`을 유지합니다.

- **[Windows 64비트 설치 파일](https://github.com/moonrisepsj/gaon-erp-releases/releases/download/v0.2.0-preview.3/GAON-ERP-Setup-x64.exe)**
- [설치 없이 압축 해제해서 쓰는 ZIP](https://github.com/moonrisepsj/gaon-erp-releases/releases/download/v0.2.0-preview.3/GAON-ERP-Windows-x64.zip)
- **[3쪽 빠른 시작 매뉴얼 PDF](https://github.com/moonrisepsj/gaon-erp-releases/releases/download/v0.2.0-preview.3/GAON-ERP-Quickstart.pdf)**
- [버전별 파일과 변경 내용](https://github.com/moonrisepsj/gaon-erp-releases/releases)

## 설치와 시작

1. `GAON-ERP-Setup-x64.exe`를 다운로드해 설치합니다. Windows 10/11 x64용입니다.
2. 바탕 화면 또는 시작 메뉴에서 **GAON ERP**를 엽니다.
3. 사내망 또는 회사 VPN에 연결한 뒤 관리자가 안내한 HTTPS 서버 주소를 넣고 **연결 확인**을 누릅니다.
4. **직원 로그인**으로 열린 기본 브라우저에서 회사 계정으로 로그인합니다.
5. GAON ERP로 돌아오면 권한에 맞는 업무 화면이 열립니다.

ZIP 버전은 압축을 모두 푼 뒤 폴더 안의 `GAON ERP.exe`를 실행하세요. EXE 하나만 따로 옮기지 마세요.
앱 메뉴의 **도움말 → 빠른 사용 안내**에서도 매뉴얼을 볼 수 있습니다.

## 현재 배포 상태

`0.2.0-preview.3`은 OS 업무 알림을 포함한 서버 접속형 검수 배포본입니다. 설치·ZIP·매뉴얼·SHA256 파일을 공개했습니다. **사내망·검수용 VPN HTTPS 주소는 별도 준비가 필요합니다.**
파일 다운로드와 설치는 가능하지만, 주소와 직원 계정이 제공되기 전에는 실제 ERP 업무에 접속할 수 없습니다.
이 설치 파일을 받는 것만으로 내부 ERP 서버가 공개되거나 업무 자료가 복사되지는 않습니다.

설치 프로그램은 아직 코드 서명 인증서가 없는 버전입니다. Windows에서 게시자 확인 안내가 표시될 수 있습니다.
은행 송금, 문자 실발송 등 외부 연동은 운영 서버의 연결·승인 상태에 따라 사용할 수 있습니다.
ARM 및 32비트 Windows 설치본은 이 릴리즈에 포함하지 않습니다.

## 공개 범위 및 검증

공개된 소스는 Windows 접속용 껍데기와 빌드 구성, 매뉴얼뿐입니다. 직원 비밀번호는 기본 브라우저에서 입력하며,
로그인 완료 뒤 ERP 세션 상태는 이 PC에 유지됩니다. 앱의 연결 설정에서 저장한 주소와 해당 서버의 로그인 상태를 지울 수 있습니다.

빌드는 GitHub Actions의 Windows 환경에서 정책·최초 화면·IPC·패키지 파일 범위를 검사한 뒤 NSIS 설치본과 ZIP을 만듭니다. 이 버전은 설치된 EXE의 실제 창 기동과 제거까지 통과했습니다.
실제 운영 서버 로그인부터 업무 저장까지의 Windows 현장 검수는 운영 접속 주소가 준비된 뒤 진행해야 합니다.
각 릴리즈의 `SHA256SUMS.txt`에서 내려받은 파일의 무결성을 대조할 수 있습니다.

직원 로그인 뒤 **설정 → 이 기기의 알림**에서 알림 범위를 고를 수 있습니다. 앱을 열어 두거나 최소화한 동안 수신하며, Windows의 GAON ERP 알림 권한도 허용해야 합니다. 로그아웃하면 알림을 중단합니다. 새 설치본 안내를 받으면 앱을 완전히 종료한 뒤 설치형은 새 설치 파일로 갱신하고, ZIP형은 폴더 전체를 교체합니다.

외부 재택 검수는 회사에서 승인한 기기만 VPN으로 연결하는 방식으로 준비합니다. 공개 저장소의 다운로드 링크가 ERP 업무 자료를 공개하는 것은 아닙니다.

## 업데이트를 반영하는 방법

|변경 내용|관리자가 할 일|직원이 할 일|새 설치본|
|---|---|---|---|
|업무 화면·검색·계약/수납 등 웹 기능|현재 직원들이 연결한 ERP 서버에 검증한 버전 반영|작성 내용 저장 → 앱 메뉴 **보기 → 새로고침**|보통 불필요|
|서버 처리·DB 구조|필요한 DB 변경과 서버 프로그램 반영·재시작 후 저장/조회 검수|반영 안내 후 새로고침, 필요하면 직원 재로그인|웹/API 호환 범위에서는 불필요|
|설치 프로그램의 로그인·OS 알림·창 기능|새 Windows/Mac 설치본과 변경 내용 배포|앱 완전 종료 → 새 설치본으로 갱신 → 재실행|필요|

접속형 앱은 연결한 ERP 서버의 화면을 열어 사용합니다. 해당 서버에 반영한 웹 수정은 직원이 작성 내용을 저장한 뒤 새로고침하면 불러옵니다. 서버를 이전하면 새 서버가 업데이트 대상입니다.

현재 앱에는 **설치본 자동 다운로드·설치 기능이 없습니다.** Windows 설치형은 안내받은 새 설치 파일을 기존 설치 위치에 설치합니다. ZIP형은 EXE 하나만 바꾸지 말고 배포 폴더 전체를 교체합니다. 맥북도 앱을 완전히 종료한 뒤 새 앱으로 교체합니다.

새로고침은 설치 프로그램 버전을 올리는 동작이 아닙니다. 이미 다운로드한 ZIP·앱에 포함된 빠른 안내/PDF도 서버 문서만 수정하면 바뀌지 않습니다. 최신 서버 안내는 ERP 사용 설명서의 **업데이트를 적용하는 방법**에서 확인합니다.

반영 안내에는 **변경 내용 / 새 설치본 필요 여부 / 사용자가 누를 메뉴 / 확인할 화면**을 함께 적습니다. 이전 화면이 남으면 저장 후 앱을 완전히 종료했다가 다시 실행하고 관리자에게 확인 시각과 화면 이름을 알려주세요.
