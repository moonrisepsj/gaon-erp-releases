GAON ERP / 1 OF 3

처음 시작하는 날

설치하고 로그인한 뒤, 오늘 할 일부터 확인하세요.

01

설치 · 서버 연결

다운로드 페이지에서 GAON-ERP-Setup-x64.exe를 받아 실행하세요. 설치 후 바탕 화면이나 시작 메뉴의 GAON ERP를 엽니다.

사내망 또는 회사 VPN에 연결한 뒤, 관리자가 안내한 HTTPS 서버 주소를 넣고 연결 확인을 누르세요. 서버 주소가 미리 설정된 설치본은 이 단계를 건너뜁니다.

직원 로그인을 누르고, 열린 기본 브라우저에서 회사 계정으로 로그인하세요. 완료 후 앱으로 돌아오면 업무 화면이 열립니다.

02

오늘 할 일 찾기

GAON 로고를 누르면 오늘 화면으로 돌아옵니다. 처리할 업무 → 할 일에서 확인할 항목을 고르세요.

업무 종류 · 전체에서 필요한 종류를 여러 개 골라 선택 적용을 누릅니다. 건물·담당자와 검색으로 대상을 더 좁힐 수 있습니다.

항목 오른쪽 처리 버튼을 눌러 내용을 확인하고 처리하세요. 납부 안내는 문자 승인, 지난 결과는 처리 이력에서 봅니다.

TIP

내 담당 업무가 안 보인다면

오른쪽 위 설정 → 내 설정 → 내 업무 프로필에서 담당 직원 연결을 확인하세요. 표시되는 메뉴와 자료는 직원 권한에 따라 달라집니다.

배포 안내

이 버전은 Windows 10/11 64비트용 미리보기입니다. 사내망·재택 검수용 VPN 주소는 별도 안내가 필요합니다. 아직 서명 인증서가 없는 설치본으로, Windows에서 게시자 확인 안내가 표시될 수 있습니다.

GAON ERP / 2 OF 3

건물 업무, 이 순서로

건물과 기준월을 먼저 고르면 같은 정보를 반복 입력할 일이 줄어듭니다.

01

건물과 호실 선택

건물 관리 → 건물별 관리에서 건물을 선택하세요. 세대 현황에서 기준월과 호실을 확인합니다. 새 공간은 세대 등록으로 추가합니다.

02

계약 등록 · 원본 첨부

호실의 계약 → 임대계약 등록에서 임차인, 계약 기간, 보증금과 월 금액을 확인해 저장하세요. 계약서 탭의 계약서 업로드로 원본을 연결합니다.

03

청구 만들기

청구 만들기 또는 월별 청구 → 청구 생성에서 해당 월과 세대별 금액을 검토합니다. 이미 만든 청구가 있는지 확인한 뒤 저장하세요.

04

입금 확인 · 미수 기록

실제 통장 입금을 확인하고 입금 확인에서 청구와 연결하거나 호실 수납 → 입금 기록에 남기세요. 일부 입금은 받은 금액만 기록합니다.

미수 관리에서 남은 금액과 연락 기록을 확인하세요. 특이사항은 비고에 남깁니다.

05

임대인 월 정산 · 지급

세대 현황의 더보기 → 임대인 월 정산을 엽니다. 건물·월·약정·수납액·배분율·공제 비용을 검토하세요.

초안 저장 후 근거를 확인하고 월 정산 확정을 누릅니다. 지급 요청의 승인, 은행 송금 결과는 이어서 별도로 확인합니다.

반드시 구분하세요

청구 = 받을 돈 / 수납 = 실제 받은 돈 / 정산 확정 = 계산 확정입니다. 엑셀 다운로드나 정산 확정만으로 은행 송금이 완료되지는 않습니다. 자료 부족 표시가 있으면 원본부터 보완하세요.

GAON ERP / 3 OF 3

함께 보고, 끝까지 확인하기

비교 작업창과 기록을 활용하면 다른 사람에게 다시 물을 일이 줄어듭니다.

01

계약 · 수납 · 정산을 나란히

오른쪽 위 비교 작업창 → + 업무 열기로 필요한 화면을 추가하세요. 탭을 다른 탭 줄로 끌면 합칠 수 있습니다.

탭을 아래로 끌거나 팝업으로 분리를 눌러 따로 띄웁니다. 창 제목으로 이동하고, 경계나 테두리를 끌어 너비와 크기를 조절하세요.

잠시 접기로 원래 화면을 보고 열린 창에서 돌아옵니다. 탭 이름 옆 점은 저장 전 입력 표시입니다.

02

작업 · 일정 · 사진 남기기

민원·작업 → 작업 접수에서 장소·담당자·기한을 확인해 저장하세요. 작업 상세에 처리 사진과 비고를 남깁니다.

담당자는 처리 시작과 완료 처리로 상태를 바꿉니다. 내 일정과 조직 일정에서 기한을 확인하고, 연결된 원래 업무에서 수정합니다.

03

저장과 실제 완료를 구분하기

저장했어요 같은 완료 안내와 목록 반영을 함께 확인하세요. 초안·승인·발송·입금·지급 완료는 서로 다른 단계입니다.

송금 엑셀은 은행 검토용입니다. 은행에서 실제 성공한 항목만 GAON에서 완료로 기록하세요. 문자도 승인과 실제 발송 결과를 각각 확인합니다.

04

앱 업무 알림 켜기

직원 로그인 뒤 설정 → 이 기기의 알림에서 알림을 켜고, 나를 태그한 업무 또는 참여 대화방 전체를 선택하세요.

앱을 열어 두거나 최소화한 동안 알림을 받을 수 있습니다. Windows의 GAON ERP 알림 허용도 켜야 합니다.

알림을 누르면 권한을 다시 확인한 뒤 업무톡을 엽니다. 로그아웃하면 알림을 중단합니다.

업데이트와 도움말

새 설치본 안내를 받으면 앱을 완전히 종료한 뒤 설치형은 새 설치 파일로 갱신하고, ZIP형은 압축을 푼 폴더 전체를 교체하세요. 앱 메뉴 도움말 → 빠른 사용 안내에서 이 문서를 다시 볼 수 있습니다. 문의할 때는 화면 이름·시각·오류 문구만 알려주세요.
